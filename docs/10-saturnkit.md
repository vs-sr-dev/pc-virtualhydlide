# What this port gave saturnkit

saturnkit (`saturnkit/`, a submodule) was started by this port. Each
entry is a saturnkit commit and what Virtual Hydlide asked of it.

| Session | saturnkit | What |
|---|---|---|
| 1 | e926f67 | `disc`: .cue/.bin sets, IP.BIN, ISO 9660, 1st read file, extraction, CD-DA to WAV. `sh2`: SH7604 decoder (equal to capstone on all opcodes the SH-2 defines), disassembly with literal pools and register names, `--refs`, `--census`, `--find-base`. `hw`: address map, register names, BIOS service pointers, SCU vectors |
| 2 | 4ce9daa | `recomp.discover`: functions and code/data in stripped SHC programs (recursive descent, constant propagation for register calls, three switch forms, pointer and prologue seeds). `recomp.match`: the same function across programs, names carried. `sh2emu`: an SH-2 interpreter (the division helpers, 12 000 of 12 000). `hw`: BIOS 0x0600026C as seen used |
| 2 | cf3250b | `ghidra/ExportFuncs.java`: Ghidra's function list, the independent check behind `discover`'s 571 of 576 |
| 3 | fe9b8b2 | `recomp` (emit and driver): each function to C++, one module per program recognised by its crc32, guarded dispatch through registers, switches, safe points; a CMake project. `runtime/`: the SH-2 context, the work RAMs and the address map, dispatch over modules, no-hardware services, the self-test harness. `recomp.selftest`: vectors from `sh2emu`, the instruction test (every form, alone and in a delay slot, and the control flow), a program's functions that run alone; 51 448 of 51 448 on Virtual Hydlide. `sh2.encode`. `discover`: branches into delay slots, the shift ladder with an offset, data pointers kept out of the seeds (still 571 of Ghidra's 576) |
| 4 | b27b9cd | `runtime/`, the Saturn: HLE boot and BIOS services (interrupt dispatch, SCU mask, semaphores, BUP in a host file), program starts with the host stack unwound, virtual or host time, SCU interrupts, timers and DMA, the SMPC with a scripted pad, the slave as a deterministic coroutine, the CD block at its registers over .cue/.bin, the SH7604's division unit, FRT and DMAC, the VDPs as memory with the raster timing, SBL's sound-driver handshake and PCM play position, the access log and the stop report (`saturn` executable). `discover`: a pointer to a stack-frame prologue is an entry wherever it lies |
| 5 | b4007a2 | `runtime/`, on screen: VDP1 drawn in software (the chip's quadrilaterals and anti-aliased lines, every colour mode and colour calculation, clipping, the framebuffers changing at VBlank-OUT), VDP2 composed in software (NBG0–3 in cell and bitmap modes with zoom, the sprite layer, priorities, colour calculation and offsets, the back screen), the SDL3/OpenGL 4.5 window with the keyboard and a gamepad as the pad, PAL framing from IP.BIN's areas, `--headless`, `--shot`, `--dump`, `--watch` with the caller; the PCM play position in blocks of 4096 samples |
| 6 | d7e7ac7 | `runtime/`, sound: the 68000 (Musashi 4.60, MIT, vendored as a plain 68000) reset by SNDON and run 256 cycles a sample in the machine's time; the SCSP (32 slots with loops, noise, FM, envelopes, LFOs; timers and the interrupts to both CPUs; DMA; the DSP; the direct, effect and external mixes; the slot monitor); CD-DA as samples at the external input; an SDL3 audio stream, `--wav`. The sound driver's handshake HLE removed |
| 6 | 11dade0 | `recomp --hook`: a call to `sh2_hook` after chosen instructions, and the runtime's `--hook ADDR:rN=VALUE` (Virtual Hydlide's frame cap) |
| 6 | e3d7c9a | `--watch` over the work RAMs: each store with the recompiled function that made it, `--watch-vblanks` |
| 6 | 1df0c7c | `--interp`: VDP1 records the game's frames and draws the fields in between moving (commands matched by keys a game layer gives, or by look), VDP2 scroll with them; hooks that run a game layer's C++ (`sh2_hook_add`) |
